# شامل · Shamel

موقع مكتبة رقمية بخمس لغات (العربية، الإنجليزية، الإسبانية، الإيطالية، الفرنسية): مقالات وكتب وأوراق بحثية مصنّفة حسب المجالات، مع زر واتساب ونموذج تواصل.

موقع ثابت خفيف: سكربت Python واحد بلا مكتبات (`build.py`) يحوّل ملفات المحتوى إلى صفحات HTML جاهزة في `dist/`.

## إضافة محتوى
- **مقال أو كتاب أو ورقة بحثية:** انسخ أي ملف في `content/items/` وعدّله. الحقل `type` يحدد النوع (`article` أو `book` أو `paper`) والحقل `field` يحدد المجال.
  - العنوان والملخص لكل لغة في `title` و`summary`.
  - النص الكامل في `body` لكل لغة متاحة. إن غابت لغة يظهر الملخص مع روابط للغات المتاحة.
  - للورقة البحثية: ضع رابط ملف PDF في `pdf` ليظهر زر التحميل.
  - للكتاب: `author` و`era` ولون الغلاف `cover`.
- **مجال جديد:** أضفه في `content/fields.json`.
- **نصوص الموقع والاسم والترجمات:** `content/site.json`.

## الإعدادات (content/site.json)
- `whatsapp`: الرقم بالصيغة الدولية بدون + (مثال 966501234567)
- `email`
- `formEndpoint` (اختياري): رابط Formspree لاستقبال الرسائل على البريد. إن تُرك فارغاً، يرسل النموذج الرسالة عبر واتساب.
- `baseUrl`: رابط الموقع بعد النشر، لتفعيل خريطة الموقع (sitemap) وروابط اللغات لمحركات البحث.

## التشغيل محلياً
```
python3 build.py
```
ثم افتح `dist/index.html`.

## النشر التلقائي
كل دفعة إلى فرع `main` تبني الموقع وتنشره على GitHub Pages عبر `.github/workflows/deploy.yml`.
إن لم يُنشر في المرة الأولى: Settings ← Pages ← Source: GitHub Actions.
